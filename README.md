# G3 Web Studio

A professional freelance web development portfolio built to showcase website design, e-commerce development and custom web applications.

## About

G3 Web Studio is the portfolio and service website for a freelance full-stack web developer.

The site is designed to help potential clients:

* Understand the services offered
* Compare website packages
* View completed projects
* Understand the development process
* Start a project enquiry

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Environment Variables

This portfolio currently does not require environment variables or private API credentials.

Public contact information is stored in:

```text
src/data/contact.js
```

## Deployment

The portfolio is designed to be deployed on Vercel directly from GitHub.

Every new production change can be pushed to the main branch and deployed through the connected Vercel project.
